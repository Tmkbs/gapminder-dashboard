[ENGLISH INTRODUCTION]
--------------------------------------------------------------------------
Apex Terminal is a high-performance, web-based stock portfolio tracking
application built with Python. It transcends traditional Excel spreadsheets
by leveraging a robust data engine and "Aurora Glass" aesthetic design.

Key Features:
1. Robust Data Engine: Automatically ingests transaction data from Excel
   (portfolio.xlsx). Features a "Quantum Simulation Mode" that generates
   realistic market data (Price, Beta, Market Cap) if live API connections
   fail, ensuring zero downtime.

2. 3D Quantum Lab: A 3D interactive scatter plot visualizing the relationship
   between Risk (Beta), Reward (ROI), and Position Size.

3. AI Sentiment Analysis: A simulated NLP module that scores assets based
   on market sentiment (0 = Fear, 100 = Greed).

4. Professional Visualization: Includes Waterfall charts for PnL attribution,
   Sector Heatmaps, and a real-time Ticker Tape.

5. Aurora UI: Features a dynamic mesh gradient background, glassmorphism
   cards, and high-contrast typography (Inter + Fira Code).

Tech Stack:
- Core: Python 3.10+
- Frontend: Dash, Dash Bootstrap Components (DBC)
- Visualization: Plotly Express, Plotly Graph Objects
- Data: Pandas, Yfinance, Openpyxl

[中文介绍]
--------------------------------------------------------------------------
APEX 极光终端是一个基于 Python 开发的高性能 Web 端股票投资组合看板。它旨在
彻底取代传统的 Excel 记账方式，通过强大的数据引擎和“极光玻璃拟态”设计，
提供华尔街级别的可视化体验。

核心亮点：
1. 智能数据引擎：自动读取 Excel (portfolio.xlsx) 交易记录。内置“量子
   模拟模式”，当云端无法连接雅虎财经 API 时，自动生成极度逼真的行情数据
   （包括 Beta、市值、板块），确保演示时网页永不崩溃。

2. 3D 量子实验室：引入 3D 可交互散点图，支持全方位旋转，立体展示
   风险(Beta) vs 回报(ROI) vs 仓位大小 的关系。

3. AI 舆情分析：模拟自然语言处理 (NLP) 模块，为重仓股生成 AI 情感评分
   （0=极度恐慌，100=极度贪婪）。

4. 专业图表：包含用于盈亏归因分析的瀑布图 (Waterfall)、板块热力图
   (Treemap) 以及顶部滚动行情条。

5. 极致美学：采用动态流体渐变背景、毛玻璃悬浮卡片以及顶级金融字体组合。

技术栈：
- 核心：Python 3.10+
- 前端：Dash, Dash Bootstrap Components
- 可视化：Plotly
- 数据处理：Pandas, Yfinance

==========================================================================
QUICK START GUIDE / 快速启动指南
==========================================================================

1. Data Generation (Local Only) / 生成数据（仅本地）:
   Run the generator script to create a rich dataset with 30+ stocks.
   运行生成脚本，创建一个包含 30+ 只股票的丰富数据集。

   $ python make_huge_data.py

2. Run Application / 运行程序:

   $ python app.py

3. Deployment (PythonAnywhere) / 云端部署指令:

   Step 1: Upload code to Git (Local Terminal)
   -------------------------------------------
   git add .
   git commit -m "Update Apex Terminal"
   git push origin main

   Step 2: Pull code on Server (PA Console)
   ----------------------------------------
   cd ~/gapminder-dashboard
   git pull origin main

   Step 3: Update Dependencies (If needed)
   ----------------------------------------
   pip install -r requirements.txt

   Finally, click "Reload" on the Web tab.
